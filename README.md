## Featured Projects

### BudgetPair — Couples Budgeting App
**React Native · Expo · TypeScript · Hono · tRPC · Upstash Redis · RevenueCat**

A privacy-focused, local-first budgeting application that helps couples organize and coordinate their finances without requiring an account.

- Stores sensitive financial data locally for offline access and greater privacy
- Supports shared budgeting, transaction tracking, financial planning, and couple synchronization
- Uses a lightweight Hono and tRPC backend deployed on Vercel
- Uses Upstash Redis as temporary synchronization-room storage
- Includes optional Google and Apple OAuth sign-in using PKCE
- Integrates RevenueCat for lifetime Pro purchases and entitlement management
- Currently being prepared for release on the Apple App Store

### [ReserveNow — Booking System](https://github.com/PatrickRubio/ReserveNow-Application)
**Java · Spring Boot · PostgreSQL · Spring Data JPA · Hibernate · REST APIs**

A backend reservation system for managing users, service listings, availability, and time-based bookings.

- Implemented user registration and login with validation and BCrypt password hashing
- Designed RESTful APIs for listings, availability, and reservation workflows
- Created relational models for users, providers, listings, and bookings
- Added validation and scheduling-conflict prevention for time-based reservations
- Structured the application with controller, service, repository, and persistence layers
